# 🌌 Navigator for the Habitable Worlds Observatory (HWO)

¡Bienvenido/a! Este proyecto fue desarrollado en el marco del **NASA Space Apps Challenge 2024**. Es una aplicación web interactiva diseñada para mapear y visualizar exoplanetas potencialmente habitables que podrían ser caracterizados por el futuro Observatorio de Mundos Habitables (HWO) de la NASA.

🔗 **Link del Proyecto en Vivo:** [Visita la aplicación aquí](https://courageous-liger-d4c848.netlify.app/)

---

## 🚀 Descripción del Proyecto

El objetivo principal de esta herramienta es permitir a los usuarios explorar los exoplanetas detectados en nuestra galaxia y entender cómo el diámetro de la lente del telescopio influye en nuestra capacidad para caracterizarlos y estudiar su habitabilidad. 

Tomando como punto de referencia central al planeta Tierra (marcado en verde), el mapa proyecta de forma interactiva la distancia y propiedades de diversos sistemas estelares y exoplanetas.

### ✨ Características Principales
* **Visualización Dinámica:** Mapa interactivo en 2D/3D de exoplanetas referenciados desde la Tierra.
* **Simulador de Apertura de Telescopio:** Un slider en la esquina superior derecha permite modificar el diámetro hipotético de la lente del HWO para observar qué exoplanetas se vuelven "caracterizables" según la potencia óptica.
* **Datos al Detalle (Tooltips):** Al pasar el cursor sobre cualquier estrella o exoplaneta, se despliega información clave y detallada en tiempo real.

* **Procesamiento de Datos Astronómicos:** Lograr representar de manera intuitiva datos de distancia y habitabilidad espacial en una interfaz web comprensible para el usuario.

* **Trabajo bajo Presión:** Diseñar, desarrollar y desplegar un producto funcional y estético en un lapso de 48 horas.
